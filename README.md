An official website and multi-portal event platform for Stellar Surge.

## Local setup

1. Copy `.env.example` to `.env` and configure MySQL.
2. Run `composer install` and `npm install`.
3. Run `php artisan migrate --seed`.
4. Run `npm run build`.

The Filament admin panel is available at `/admin`.
